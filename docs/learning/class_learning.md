# modifier(제어자)
제어자는 클래스, 변수, 메서드가 
- 어디에서 사용할 수 있는지
- 객체마다 따로 존재하는지
- 변경 가능한지
- 상속 가능한지
를 결정한다.

## public
```public```은 **어디서든 접근할 수 있다**는 뜻
- 다른 패키지에서도 사용할 수 있는 class라는 뜻

## private
```private```는 **해당 클래스 내부에서만 사용할 수 있다**는 뜻
- 메서드를 통해 접근가능
-> 이렇게 하는 이유는 객체의 데이터를 함부로 변경하지 못하게 하기 위함


```private -> 내부 데이터 보호``` 이것이 객체지향의 **캡슐화**와 관련이있음

## 접근 제어자 네 가지
- public: 모든 곳
- protected: 같은 패키지 + 자식 클래스
- 생략: 같은 패키지
- private: 같은 클래스 내부

아무것도 쓰지 않는 경우 -> 이것은 ```public```이 아니다.

같은 패키지 안에서만 사용할 수 있음

이를 보통 **default 접근 수준** 또는 **package-private**라고 부름

주의할 점은 실제로 ```default```라는 키워드를 쓰는 것이 아니라, 그냥 아무것도 쓰지 않는 것

## static
객체에 속하지 않고 클래스 자체에 속한다.

-> ```static``` 메서드는 객체를 만들 필요가 없이 바로 사용가능

왜냐하면 클래스 자체에 속해있기 때문

```
일반 메서드 -> 객체에 속함

static 메서드 -> 클래스에 속함
```

## 일반 변수와 ```static``` 변수 차이

일반변수는 각 객체가 다른 값을 가지지만,

```static``` 변수는 모든 객체가 공유

## ```public static```

두 제어자를 함께 사용할 수 있음


public -> 어디서든 접근 가능

static -> 객체 없이 클래스 이름으로 호출 가능

## ```public static void main```

```java
public static void main(String[] args){}
```
각 부분을 나눠보면


```public```

JVM이 외부에서 이 메서드를 실행할 수 있어야 합니다.

public -> JVM이 접근할 수 있음

```static```

프로그램 시작 시 아직 객체가 만들어지지 않았기 때문에, 객체 없이 호출할 수 있어야 함

-> Main 객체를 만들지 않고 호출 가능

```void```

메서드가 실행 후 값을 반환하지 않는다는 뜻

-> 반환값 없음

```main```

Java 프로그램의 시작점으로 정해진 메서드 이름

```String[] args```

문자열 배열, 터미널에서 실행할 때 전달한 값을 받음

## final
**변경할 수 없게 한다**


변수에 사용하면 한 번만 값을 넣을 수 있음, 이후 변경 불가능

```public static final String DATABASE_NAME = "database.db";```

어디서든 사용가능하고, 객체 없이 클래스에서 사용하며, 값 변경 불가

상수 이름은 일반적으로 대문자와 밑줄을 사용

## final calss

이 클래스는 상속할 수 없음

설정 클래스나 유틸리티 클래스처럼 상속할 이유가 없는 클래스에 사용하기도 함

## final 메서드

자식 클래스가 이 메서드를 재정의할 수 없음

즉, **override**를 막음

## private 생성자

외부에서 객체를 만들지 못하게 하는 것

## abstract

미완성 클래스 또는 미완성 메서드를 의미

## synchronized

여러 스레드가 동시에 같은 코드나 데이터에 접근하지 못하도록 제어

멀티스레드 환경에서 데이터 충돌을 막을 때 사용

## transient
객체를 파일이나 네트워크로 직렬화할 때 제외할 필드에 사용

## volatile
여러 스레드가 변수를 사용할 때 최신 값을 읽도록 보장하는데 사용

## static은 언제 사용해야 하는가?
객체마다 데이터가 다른가? -> 일반 메서드/변수

객체 상태와 관계없는 공통 기능인가? -> static고려



# 자주 사용하는 정규표현식 요약

| 표현식      | 의미           | 예시          |
| -------- | ------------ | ----------- |
| `.`      | 아무 문자 하나     | `a.c`       |
| `[abc]`  | a 또는 b 또는 c  | `[abc]`     |
| `[0-9]`  | 숫자           | `123`       |
| `[a-z]`  | 소문자          | `abc`       |
| `[A-Z]`  | 대문자          | `ABC`       |
| `[^0-9]` | 숫자가 아닌 문자    | `-`, 공백     |
| `\d`     | 숫자           | `123`       |
| `\D`     | 숫자가 아닌 문자    | `abc`       |
| `\s`     | 공백           | `" "`       |
| `\S`     | 공백이 아닌 문자    | `a`         |
| `\w`     | 영문자, 숫자, `_` | `abc123`    |
| `\W`     | 단어 문자가 아닌 문자 | `!@#`       |
| `*`      | 0개 이상        | `a`, `aa`   |
| `+`      | 1개 이상        | `aa`, `aaa` |
| `?`      | 0개 또는 1개     | `a`, 없음     |
